# 红薯台

本机部署的小红书多账号内容运营中台。当前版本完成了团队账号、选题、认领、Codex 手工导入、草稿、审核、发布排队和操作日志的第一条可运行闭环。

## 本机启动

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。首次打开时创建管理员账号；随后可在“系统设置”中为每位工作人员创建独立账号。

`npm run dev` 会同时启动网页和小红书运行管理器。运行管理器只提供两个动态槽位，账号平时休眠；扫码、检查或发布时才会按需启动 MCP，空闲十分钟自动关闭。

本地业务数据由开发服务器的 D1/SQLite 兼容数据库保存，不依赖云服务。不要删除 `.wrangler` 目录，否则本地开发数据会丢失。

## 已完成

- 首次管理员初始化、独立登录、七天会话和退出
- PBKDF2-SHA256 密码哈希，本地数据库不保存明文密码
- 管理员创建内容运营、审核员、发布员和只读成员
- 只展示真实添加的小红书账号，不显示示例账号
- 从账号中心添加账号、获取登录二维码并检查登录状态
- 最多5份独立账号数据复用2个动态运行槽位
- 每个账号独立 Cookie、配置和日志目录
- 登录后绑定小红书用户ID，身份不匹配时阻断操作
- 选题创建、认领和同选题按账号去重
- 草稿编辑、Codex 提示词复制、JSON 结果导入
- 提交审核、退回原因、审核通过快照和发布排队
- 全流程审计日志
